## 三、链接公开可访问的自检方法

提交前逐条检查，确保评分老师不需要登录、不需要申请权限就能看到笔记：

1. **无痕窗口打开**：用浏览器的无痕 / 隐私模式（Ctrl+Shift+N 或 Ctrl+Shift+P），在未登录语雀的状态下粘贴链接，能正常显示正文即视为公开可访问；
2. **退出账号再试**：退出当前语雀账号，或换一个没有登录过的浏览器打开链接，确认没有跳转到登录页或权限申请页；
3. **检查分享权限**：语雀文档的分享设置应选择「互联网上获得链接的人可阅读」一类的公开选项，而不是「仅自己可见」或「团队内可见」；
4. **确认是阅读链接**：复制的是分享后的阅读链接，不是编辑页链接；编辑链接在未登录时会要求登录或权限，属于不可访问；
5. **手机流量下抽查**：用手机移动网络（而非同一 Wi-Fi）打开一次，可以同时验证外网可访问性和链接没有被内网限制。
